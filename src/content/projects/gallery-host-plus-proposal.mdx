Gallery Host Plus starts from the reality that gallery hosts already carry a lot of the museum's public-facing care. The proposal asks what it would look like to build a path around that work instead of leaving it flat.

The pilot imagines optional cross-training, mentorship, and wellness supports so hosts can move through AV, collections, development, and other departments without pretending that growth has to happen outside the museum.

What matters most is the shape of the pathway: a clearer wage ladder, a better learning arc, and a model of institutional care that actually feels close to daily reality.
