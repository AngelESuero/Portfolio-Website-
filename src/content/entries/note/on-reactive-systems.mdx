The pattern keeps repeating: something breaks, it becomes visible, institutions respond to the visibility rather than the break. The response is always to the spectacle, never to the condition that produced it.

A system that only activates when people are loud enough to disturb it is not a responsive system. It is a system that has learned to wait.
